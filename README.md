## Data
I will be using a public dataset to train the model. I will then use my own emails as testing data. The main decision for this is my personal dataset would not be large enough to train model. I will be using the enron-spam kaggle dataset to train the model initially. The dataset is split between 71% ham and 29% spam. When splitting the data between training and testing data I will stratify this so that the percentage of ham to spam is the same in both testing and training data.
